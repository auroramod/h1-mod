# H1-Mod

H1-Mod is a client for Call of Duty®: Modern Warfare Remastered that adds dedicated servers, hands-on modding utilities, and custom content and mods like weapons, maps, models, sounds, and more. ***You must legally own [Call of Duty®: Modern Warfare Remastered](https://store.steampowered.com/agecheck/app/393080/)*** to run this mod. Unlicensed or cracked versions of the game are **NOT** supported and will not be given assistance.

## Compile from source code

- Clone the Git repo via [Git](https://git-scm.com/install/windows) or [GitHub Desktop](https://desktop.github.com/download/). **DO NOT download it as ZIP** as it will not work.
- Run the `generate.bat` script to generate the project solution.
- Build the project via the generated solution file in `build\h1-mod.sln`.
